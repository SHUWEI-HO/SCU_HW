#### 期中統整


**1. 對數報酬率 (LN RETURN)**

- 其定義為**下期股票收盤價**除以**當期股票收盤價取自然對數**
  
  $$
    R_{t+h} = \ln\left(\frac{S_{t+h}}{S_t}\right)
  $$

  其中$𝑅_{t+h}$為持有 ℎ 個月的報酬率，$S_{t+h}$為時間 𝑡 + ℎ 時股票收盤價，$S_{t}$為時間t時股票收盤價。


**2. 規模 (SIZE)**

- 市值是企業規模的代表，反映了公司的市場地位
- 對股票收益產生重大影響的因子(每天都會變動)
- 對於規模的定義:
    $$
    \textstyle \text{規模Size} = \log(\text{市值}_{t})
    $$
- 至於市值的公式則為:
    $$
    \textstyle \text{市值} = \text{收盤價} * (\text{流通在外股數})
    $$

    :star: 流通在外股數 : 是指某家公司股票中**目前可供市場上自由交易的股份數量**

**3. 小公司效應**

- 其定義為**小盤股**比大盤股的**收益率**高
- 股票市值會隨著公司的規模增大而減少
  
**4. 帳面市值比/淨值市價比 (Book-To-Mark)**

- 定義為將**帳面價值**與**其市場價值**比較進而評估一家公司的價值
- 公式如下:
    $$
    \text{帳面市值比/淨值市價比} = \frac{\text{普通股東權益}}{\text{市值}} = \frac{1}{\text{股價淨值比}}
    $$

:bulb: **帳面市值比效應(BM效應)**
- 定義為 帳面市值比較高的公司**平均月收益率**高於帳面市值比較低的公司

**5. 動能 (Momentum)**

- 定義為**觀察上漲或下跌的資產價格或投資報酬有繼續上漲或下跌的趨勢**
- 將採用形成期12個月計算以報酬率形成的動能，概念為𝑡 − 1期股票收盤價除以𝑡 − 12期股票收盤價取對數，不受基期和時間影響(也就是說**每一個月都會往前回推12個月，然後計算那段 12 個月的對數報酬率**)
- 公式如下:
  $$
  \text{動能Momentum} = ln(\frac{S_{t-1}}{S_{t-12}})
  $$
:bulb: **動能效應** : 過去表現強勁(動能大)的股票，下一個期間表現會繼續優於過去表現較差(動能小)的股票 $\rightarrow$ **強者恆強**

**6. 資訊係數 (Information Coefficient, IC)**

- 定義: 股票的因子與股票下期報酬率的相關係數
- 透過IC值可以**判斷因子對下期報酬率的預測能力**
- IC值介於-1與1之間(相關係數)

| IC  | 表現情形                         |                                                                                                  |
| --- | -------------------------------- | ------------------------------------------------------------------------------------------------ |
| > 0 | 當期因子與下期報酬率有**正相關** | - 某公司因子值很**高**，這公司下期報酬就會**漲** <br> - 因子值很**低**，這公司下期報酬就會**跌** |
| < 0 | 當期因子與下期報酬率有**負相關** | - 某公司因子值很**高**，這公司下期報酬就會**跌** <br> - 因子值很**低**，這公司下期報酬就會**漲** |

:bulb: **IC的絕對值越大 $\rightarrow$ 表示該因子對於下期報酬率的影響越大**

- 常見IC有兩種:
  | 類型                | 定義                                                           | 公式                                                                                           |
  | ------------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
  | Normal IC(通常使用) | 在時間點 𝑡 時因子與持有 ℎ 個月的報酬率間的相關係數             | $ Normal IC_{t} = corr(X_{t}, R_{t+h}) $ ; h代表持有h個月的報酬                                |
  | Rank IC             | 在時間點 𝑡 時因子**排序**與持有 ℎ 個月的報酬率排序間的相關係數 | $ Rank IC_{t} = corr(r(X_{t}), r(R_{t+h}))$ ; r 表示將動能因子與對數報酬率排序, 在計算相關係數 |

**7. 投資策略步驟**

計算出持有h個月的對數報酬率 $\rightarrow$ 計算選取的因子，如上面的BM(帳面市值比)、Size(規模)、Momentum(動能)等等 $\rightarrow$ 計算該對應的歷史IC $\rightarrow$ 挑選各個時間點，所有因子中**絕對值最大**的因子，作為投資策略的基準 $\rightarrow$ 做家數等分 計算各個區間的買低、買高、賣低及賣高(總和平均且必須將該因子對應該年的數值先做排序:由高到低)

之後判斷如下:

| 預測IC | 投資策略             |
| ------ | -------------------- |
| > 0    | 買高(等分)賣低(等分) |
| < 0    | 賣高(等分)買低(等分) |

:star: **比較大盤**
- 計算勝率: 將各個時間點的所有等分的質與真實大盤的報酬率做比較，若大於真實大盤則為1，反之為0 ，最後各等分的所有年分加總做平均
- 計算累積報酬: 將各等分的所有年分累積加總


**8. 建構投資組合策略**

若不選因子直接做策略，每個因子都有9種策略 :

|     情形     | 策略                                       |
| :----------: | ------------------------------------------ |
| 不管IC>0或<0 | 買高、買低、賣高、賣低、買高賣低、買低賣高 |
|    IC > 0    | 買高、賣低、買高賣低                       |
|    IC < 0    | 賣高、買低、賣高買低                       |

若選IC值絕對值最大的因子則:


|     情形     | 策略                                       |
| :----------: | ------------------------------------------ |
| 不管IC>0或<0 | 買高、買低、賣高、賣低、買高賣低、買低賣高 |
|    IC > 0    | **買高賣低**                               |
|    IC < 0    | **賣高買低**                               |
