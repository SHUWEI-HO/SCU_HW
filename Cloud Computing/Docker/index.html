東吳大學資料科學系

簡介

東吳大學資料科學系致力於培養具備數據分析、機器學習和數據管理技能的專業人才。我們的課程涵蓋從數據收集到分析、預測建模等全方位的知識，幫助學生在大數據時代中脫穎而出。

課程與項目

我們的核心課程包括數據分析概論、機器學習、數據庫系統等。此外，學生還可以選修高等數據視覺化、深度學習、大數據處理技術等專業方向課程。
